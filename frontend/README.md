# Frontend Component — Telecom Churn Platform

React + TypeScript + Tailwind CSS + shadcn/ui application.

## Directory Structure
- `src/components/` — UI primitives, Recharts, ECharts scatter plot, customer table components
- `src/pages/` — Dashboard, Customers, CustomerDetail, Segments, ModelMonitoring, Admin
- `src/lib/` — API fetch client and formatters
- `src/types/` — TypeScript schema interfaces
- `src/routes/` — React Router setup and RBAC guards

## Commands
- `npm run dev` — Launch Vite local development server
- `npm run build` — Compile TypeScript and bundle production assets
